Login & OTP verification

Use this page to sign in to your account. Enter your username and password, then complete the one-time code check if your account requires extra security.

  • Forgot password takes you through the reset process if you cannot sign in.
  • Register is for creating a new user account and may require an OTP confirmation.
  • If you are accessing the institution portal, you may need to confirm a secure link before you continue.

Dashboard

Your dashboard is the home page for your work. It gives you a quick overview of the tasks, documents, and compliance issues relevant to your role.

  • Check the key information for your team, department, or personal documents.
  • The content you see depends on your role, such as Department Admin, Stakeholder, or Super Admin.

Institution Portal · Request Documents

This is where an institution can request the documents it needs. The portal keeps everything in one place so you can view your requests and see which ones were approved.

  • Request Documents lets you choose the documents needed and send the request.
  • My Requests shows the status of each request.
  • Approved Documents lists the documents that your institution is allowed to access.
Back to top

Documents · Upload Document

Use this area to add a file to the system and fill in the details needed for review. It is the main place for uploading and managing documents.

  • All Documents lets you view the document list.
  • Document Requests helps you track access or approval requests.
  • Only users with the correct permissions can upload or manage files here.

Compliance status

This page shows whether documents and records meet the required compliance checks. It helps you quickly see what is complete and what still needs attention.

  • Compare the required documents with what has already been uploaded.
  • Check whether a department or institution is missing required evidence.
  • Use the reports page to look at the overall compliance picture.
Back to top

Reports

Reports are summary views that help you understand activity, compliance, and document status at a glance. They are useful when you need a clear snapshot instead of checking each record one by one.

  • Use the report pages to monitor document activity and compliance progress.
  • Some reports are monthly or scheduled, while others are for quick review.
  • Super Admin users usually have access to the full report set.
Back to top

Audit Log

The audit log shows what happened in the system and who did it. It is useful when you need to check actions, approvals, sign-in events, or other changes.

  • Use it to confirm who performed a task and when it happened.
  • It is especially helpful for checking login events, document actions, approvals, and settings changes.

User Management & Roles Management

This area is where administrators manage people, roles, and access levels. It helps keep each user in the right group and gives them only the permissions they need.

  • Roles Management controls which rights are assigned to each role.
  • Institutions stores the organizations connected to the system.
  • Departments and Department Admin assignments help organize access across teams.
Back to top

System Settings

System Settings lets administrators control security and document rules. This is where you can set how long access codes, sessions, and document expiry rules stay active.

  • Verification codes: decide how long sign-in and registration codes stay valid.
  • Sessions: control how long users stay logged in before they need to sign in again.
  • Links: decide how long invitation and password reset links remain usable.
  • Security limits: manage retries and timeouts to help protect the system.
  • Use Reset to default if you want to undo a change.
Back to top

Institutions

This page keeps records of the institutions connected to DocuVault. These records help the system manage access, requests, and the correct institution-level setup.

  • Use Add Institution to create a new record.
  • You can search for institutions by name, domain, registration number, or type.
  • Send Access Link creates a secure link for institution users to access the portal.
Back to top

Department Requests

This page shows requests that still need review before they are sent to the right person. It helps departments manage document work in a clear order.

  • Review the request and choose the user it should be routed to.
  • Approve accepts the request and moves it forward.
  • Deny rejects it and records the reason.
Back to top

Backup and Restore

Backups are safety copies of the system. This page lets administrators create a backup and restore the system if needed.

  • Create Backup Now makes a fresh copy of the current system state.
  • You can view the backup history and choose a backup to restore.
  • Restore brings back the selected saved version of the system.
Back to top

Document Type Validity

This section controls how long a document type stays valid. It helps you decide when files expire and when users should be warned before that happens.

  • Every document type is valid for a set number of months, counted from the date the copy was certified or the date it was uploaded. No document is valid forever.
  • The validity can be based on the Certification date or the Upload date.
  • Warning days tells the system how early to warn users before expiry.
  • Review impact shows how many current documents will change status after the new rule is saved.
