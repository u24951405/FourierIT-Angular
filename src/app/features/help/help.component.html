Login & OTP verification

Start at /auth/login. Enter your username and password, then continue through the normal sign-in flow. If your account is configured for MFA or OTP validation, you will be guided to the verification step before access is granted.

  • Forgot password is available from the login screen and sends the user through the reset flow.
  • Register is available for new user onboarding and may require OTP confirmation before the account is activated.
  • For institution access, the portal flow begins at /institution/auth/access and verifies the secure token before moving to /institution/auth/verify.

Dashboard

After login, the Dashboard is the main landing area. It shows the operational overview for the current user scope: the system dashboard for super admins, the department dashboard for department-scoped users, or the personal document dashboard for document owners.

  • Use the dashboard to review key compliance information and quick access areas.
  • Navigation depends on your role and access permissions, including Department Admin, Stakeholder, or Super Admin.
Back to top

Institution Portal · Request Documents

The institution portal is accessed from /institution/dashboard and supports the registration, request, and monitoring flow for external institutions. The work is grouped under the live tabs: Home, Request Documents, My Requests, and Approved Documents.

  • Request Documents lets an institution select the document types it needs and submit the request.
  • My Requests tracks the status of those submissions.
  • Approved Documents displays the documents the institution is allowed to access.
Back to top

Documents · Upload Document

The document workflow is centered on Documents in the sidebar and the route /documents/upload. This is where document owners upload files and assign the relevant metadata for review.

  • Use All Documents to browse the document registry.
  • Use Document Requests to follow access or validation requests.
  • Only users with the permitted role can submit or manage uploads.

Compliance status

Compliance is the operational status view for FICA/KYC requirements and required-document checks. The live system exposes this through the dashboard and the report pages, and the summary is evaluated against the configured requirements for departments, owners, and institutions.

  • Review required versus uploaded documents.
  • Check whether a department or institution is missing required evidence.
  • Use the report pages to find the compliance picture across the system.
Back to top

Reports

Reports are grouped under /reports and include the system reporting pages such as View Document Activity Report, Compliance, Activity, and other operational summaries. These pages pull together document activity, compliance posture, and audit details into a reviewable format.

  • Use the summary pages to monitor document volumes and compliance progress.
  • Ad-hoc and monthly report views are available in the reporting module.
  • Super Admin users typically have access to the full report set.
Back to top

Audit Log

The Audit Log page is a security and operations review screen for changes, requests, OTP events, and administrative activity. It is intended for control and accountability checks across the platform.

  • Use the audit log to confirm who performed key actions and when.
  • It is especially useful for investigating login, OTP, request, approval, and configuration changes.

User Management & Roles Management

User administration is handled in the User Management and Roles Management sections. These reflect real routes such as /users/department-admins, /users/document-owners, /users/stakeholders-compliance, and /administration/roles.

  • Roles Management controls role setup and permissions.
  • Institutions manages institution records and related access setup.
  • Departments and Department Admin assignments are managed from the same administration area.
Back to top

Timer Settings

The Timer Settings page is available under /system-settings and is used to manage expiry and session timing controls, including OTP expiry and institution session timing values. This section is intended for administrators who need to tune operational timers.

  • Use the page to review and update system-defined timer values.
  • Changes are relevant to OTP windows and authenticated session lifetimes.
